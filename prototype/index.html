BBPlayer Desktop · 样式原型

静态 HTML，没有逻辑与数据。只看布局与视觉。

主页 最近播放 · 快捷入口 · 听歌频率 · 最近更新 · 播放历史 正在播放 唱片 + 歌词（纯文字流） 歌单 页头 + 紧凑歌曲行 + 多选工具条 收藏夹 卡片列表 + UID 工具条 音乐库 歌单卡片网格 搜索 结果用与歌单相同的歌曲行 弹层 队列浮层 · 歌曲菜单 · 添加到歌单 · 新建歌单 设置 分类列表 + 子页

本原型已落实的决定

  • 播放条在所有页面底部固定（窗口固定底行，换页不动）
  • 播放模式四档：列表循环 / 单曲循环 / 随机播放 / 顺序播放
  • 没有音量滑块（快捷键 Ctrl + ←/→ 调节）
  • 搜索框常驻内容卡顶部
  • 标题栏完全自绘（无系统边框）
  • 没有右侧栏，队列走播放条「播放列表」按钮的浮层
  • 收藏夹卡只显示 N 个视频
  • 主页播放历史是独立区块
  • 听歌频率是 GitHub 贡献墙（53 周 × 7 天）
  • 歌词是纯文字流，不是卡片
  • 点击目标按鼠标交互（26–34px）
  • 主题默认中性浅色（白底深灰强调色）
  • 封面全是拉取到的视频封面（原型用占位图）
  • 图标是内联 SVG，不依赖网络字体
